# ZenVora

### Read the Pulse of Every Classroom

ZenVora is an AI-powered Student Feedback Sentiment Analysis System designed to collect, analyze, and understand student feedback to improve educational quality.

## Features

- Student Registration and Login
- Email OTP Verification
- Course-wise Feedback
- Star Rating System
- Sentiment Analysis
- Student Dashboard
- Admin Dashboard
- Feedback Management
- Lost and Found Management

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Ajal-hari/zenVora.git
```

2. Open the project folder:

```bash
cd zenVora
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate it:

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements-local.txt
```

6. Run database migrations:

```bash
python manage.py migrate
```

7. Start the server:

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
